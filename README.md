# Basic-Weather-Application
A simple command line python program to display the current weather of a place based on lat and lon.

##Issues

Took me a little while to figure out how to use requests and get the info I needed.

I wanted it to tell you what the current conditions were, but the weather code was just giving me a number 
so I had to make a function to convert the most common codes to a condition statement.

When I was adding the input function, I wanted to make sure the weather was accurate based on the coordinates, 
so I did a couple of tests, and did in fact verify that the information is correct

Wanted to have the ability to change the units, and I also needed to have units on the display at the end, so I figured out the 
syntax for the URL to append units and asked the user which ones they wanted: imperial (default) or metric
